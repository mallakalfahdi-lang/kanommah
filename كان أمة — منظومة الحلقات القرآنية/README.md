# كان أمة — منظومة إدارة الحلقات القرآنية

تطبيق ويب كامل (Full-stack) لإدارة حلقات تحفيظ القرآن الكريم للطالبات: الطالبات، المعلمات، المشرفات، والإدارة العامة.

## الوحدات

- **واجهة عامة**: تسجيل الدخول، إجبار تغيير كلمة المرور الافتراضية عند أول دخول.
- **بوابة الطالبة**: لوحة شخصية، حلقاتي والتسجيل في الحلقات، سجل الحضور، الدرجات، الحفظ والتسميع، الأنشطة والتسليمات، العيادات والمواعيد، التعزيزات، الرسوم ورفع الإيصالات، الطلبات، التنبيهات.
- **بوابة المعلمة**: لوحة المعلمة، حلقاتي، طالباتي، التحضير اليومي، إدخال وإرسال الدرجات، ملاحظات التسميع، الأنشطة والتصحيح، مواعيد العيادات، التعزيز، التقييم العملي، طلبات التسجيل.
- **بوابة المشرفة/الإدارة**: لوحة تحكم، ملف الطالبات والمعلمات، الحلقات والشعب (مع المواعيد والنشر)، كشف الدرجات، التقييم العملي، المواعيد، التعزيز، التنبيهات، الطلبات، المدفوعات وتوليد السجلات الشهرية، التقارير، المستخدمون، الفروع، إعدادات المنظومة.
- **مشترك**: الرسائل، الإشعارات، الملف الشخصي وتغيير كلمة المرور.

## التقنية

- **الخادم**: Node.js + Express 4 + SQLite (better-sqlite3) — المصادقة بجلسات (scrypt + توكن)، صلاحيات حسب الدور، ونطاق المشرفة مقيّد بفرعها.
- **الواجهة**: React 18 + Vite + React Router (HashRouter) + lucide-react، تصميم عربي RTL متكامل ومتجاوب.

## التشغيل

```bash
# الخادم (يشغّل الواجهة المبنية وواجهات API معًا)
cd server && npm install && npm start        # المنفذ الافتراضي 4180 (PORT لتغييره)

# الواجهة (تطوير)
cd client && npm install && npm run dev      # المنفذ 5180 مع تمرير /api إلى 4180
cd client && npm run build                   # إنتاج مجلد dist الذي يخدمه الخادم
```

قاعدة البيانات تُنشأ وتُهيّأ تلقائيًا في `data/app.db` مع بيانات تأسيسية (فرعان، 5 حلقات، 12 طالبة، 5 معلمات، مشرفتان، حساب إدارة عامة).

## الحسابات التجريبية

| الصفة | اسم المستخدم | كلمة المرور |
|---|---|---|
| إدارة عامة | `admin` | `Admin@2026` |
| مشرفة فرع ضياء | `supervisor1` | `Super@2026` |
| مشرفة فرع سراج | `supervisor2` | `Super@2026` |
| معلمة | `teacher1` … `teacher5` | `Teacher@2026` |
| طالبة | `student1` … `student12` | `Student@2026` |

> عند أول دخول لحسابات الإدارة والمشرفات تُطلب كلمة مرور جديدة.

## نسخ احتياطي

انسخ مجلد `data/` (يحتوي قاعدة البيانات ومرفقات الرفع) لأخذ نسخة كاملة من بيانات المنظومة.
